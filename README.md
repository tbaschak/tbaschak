## 👋 Hi, I'm Theo

Network engineer, infrastructure enthusiast, open-source tinkerer, and professional packet wrangler based in Winnipeg, Canada.

- 🌐 **Networking:** BGP, IPv6, MPLS, DNS, RADIUS/AAA, and generally making packets go where they're supposed to.
- 🛠️ **Building:** Network automation, infrastructure tooling, monitoring systems, and increasingly, things written in Go.
- 🏢 **Work:** Running [Hextet Systems](https://hextet.net), helping ISPs, WISPs, and businesses build and improve their networks.
- 🌎 **Internet infrastructure:** [Manitoba Internet Exchange](https://www.mbix.ca/) board member, IPv6 advocate, and operator of AS395089.
- 🦎 **Open source:** Building tools to solve real-world networking problems, occasionally creating new ones along the way.
- 🤝 **Collaboration:** Interested in networking tools, automation, internet infrastructure, and useful open-source projects.
- 📫 **Find me:** [@theo@infosec.exchange](https://infosec.exchange/@theo)

*Keeping the packets flowing, one questionable configuration at a time.*
